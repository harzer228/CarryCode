# Changelog

## Unreleased

- CarryCode Agent CLI открывается пунктом **1** в Lite и Full. Внешние CLI показываются в Full.
- В Windows агент сам выбирает окно. Разрешение в Ask и Auto действует на текущий чат, Full access пропускает запрос. Управление останавливается с помощью F8 или Ctrl+Alt+Shift+F12.
- `/cd` меняет папку проекта с сохранением истории. `/setting` открывает настройки языка, темы, рабочего стола и саб-агентов.
- Настраиваемый лимит позволяет запустить до 30 саб-агентов одновременно. Агент запоминает ограничение параллельных запросов для подключения.
- Уточнены английские и русские подписи, сообщения об ошибках и встроенные скиллы.

## 0.1.0-beta.6.2 — 2026-11-24

- Добавлена функция `delegate`: после подтверждения запускает до двух параллельных read-only саб-агентов (Исследователь и Ревьюер) через активного провайдера.
- Исправлены край логотипа в цветовых темах и направление стрелок в выборе API и изображений.
- При смене или очистке диалога черновик плана сбрасывается. Переключение в «Только чат» через F6 применяется со следующего сообщения, в том числе для `delegate`.

- **Shift+Enter** и **Ctrl+Enter** добавляют строку в поле сообщения; запасное сочетание — **Ctrl+J**.
- Во время ответа первое **Esc** показывает подсказку, второе менее чем через 7 секунд прерывает ответ; после этого интервала подтверждение сбрасывается.
- `/theme` выбирает одну из четырёх тем, включая оформление в стиле Claude Code, и сохраняет выбор в переносимом профиле.

- **F7** в проводнике открывает отдельный диалог создания папки с предпросмотром пути. В Windows ввод `\Test` создаёт `Test` внутри текущей папки.

- `/continue` появился в меню команд и справке. Если продолжать нечего, агент сообщает об этом вместо ошибки «Неизвестная команда».

- **F3** в форме модели позволяет отметить несколько уровней для `/reasoning`. Сопоставления API доступны отдельно через **F2**.
- В режиме планирования рамка ввода показывает выделенную метку **PLAN MODE** вместо длинной подсказки.
- Автозаполнение читает расширенные метаданные Melious и при необходимости запрашивает лимиты по точному ID модели, не заменяя введённые вручную значения.

- `/plan` переключает режим планирования. `/code` показывает план и после подтверждения сразу запускает реализацию с текущими разрешениями.
- `/header` скрывает или возвращает верхнюю панель; миллион токенов отображается как `1M`.

- Проектные MCP-серверы запускаются после подтверждения в `/mcp` только на текущий сеанс. Проектный `.mcp.json` доступен напрямую и не импортируется в настройки пользователя.

- `/provider` управляет подключениями и ключами, а `/model` группирует модели по провайдерам и импортирует выбранные из каталога. **F5** заполняет пустые поля, **T** отдельно проверяет выбранные параметры reasoning. Старые подключения, модели и история переносятся из зашифрованного профиля.
- Вход и выход модели могут совпадать с окном контекста. CarryCode ограничивает выход свободным местом для конкретного запроса и показывает оценку в `/status`.
- Режим **Агент / Только чат** переехал в `/permissions` (**F6**). Он сохраняется для каждого диалога. При смене во время ответа применяется со следующего сообщения.
- Подсказка об увеличении окна сразу видна в узком терминале.
- Установщики Windows Lite и Full добавляют удаление из параметров Windows и из папки комплекта. Зашифрованный профиль, настройки и проекты сохраняются.

## 0.1.0-beta.6.1 — 2026-11-23

- В правом углу чата виден процент заполнения контекста. `/status` показывает оценку занятых и оставшихся входных токенов.
- Встроенный веб-поиск Mwmbl доступен в Lite и Full без Docker и API-ключа. Он включён для новых профилей агента и доступен через `/search` в существующих.
- Исправлены вызовы Git из агента при запуске CarryCode из среды с переменными `GIT_CONFIG_COUNT` и `GIT_CONFIG_KEY_*`.
- Браузер ждёт завершения закрытия вкладки перед обновлением списка и переключением на другую.
- Браузер продолжает ждать ответ при кратком тайм-ауте чтения и указывает имя операции, если ожидание истекло.
- Повторный запрос активного режима разрешений показывает его состояние без ошибки инструмента.

## 0.1.0-beta.6 — 2026-11-23

- Пустые лимиты в настройках модели заполняются из каталога при сохранении. `/model` показывает добавление новой модели, сохранённое подключение и каталог провайдера.
- Таймер стартует после отправки. Под итоговым ответом видны длительность, расход токенов и скорость. При обрыве потока агент один раз повторяет сетевой запрос и оставляет возможность продолжить через `/continue`.
- Текст файлов из `@` скрыт в истории. Длинные вставки показываются компактной меткой. В Windows **F7** вставляет текст из буфера прямо в CarryCode.

- Выпущены два установщика Windows. Lite включает CarryCode Agent, а Full также содержит Codex CLI и OpenCode для Windows и Linux.

- `/search` отправляет интернет-запросы через SearXNG или Brave Search. Разрешения можно сменить во время работы, настройки модели применяются со следующего запроса.
- Новые чаты начинают с режима «Подтверждать за меня». Веб-поиск запускается без подтверждения и отменяется по Esc. При выборе локального SearXNG CarryCode проверяет, что сервер отвечает на поисковый запрос.
- Исправлены всплывающие ошибки загрузки рантаймов Windows и простые цепочки `&&` в Windows PowerShell 5.1.


- Диалоги, подтверждения команд и изменения проекта доступны на экране чата. Новый чат начинает с чистой статистики, а остановка ответа сохраняет черновик.
- Добавлены подсказки по `/` и `@`, копирование выделения через несколько экранов и команда `/permissions`.
- Shell выбирает PowerShell 7 при наличии, показывает код завершения и сохраняет вывод при остановке. Автоматические команды используют песочницу, а запасной запуск требует разового подтверждения.


- Добавлены создание проекта и файлов, подтверждение группы правок и проверяемая отмена. Агент умеет читать диапазоны строк, искать по шаблону, смотреть Git-статус и diff.
- Добавлены shell с подтверждением и раздельным выводом stdout/stderr, предварительный просмотр статических сайтов и обнаружение типовых задач проекта.
- Rust-клиент `/browser` запускает установленный Chromium в фоне и даёт агенту дерево страницы, консоль, ошибки сети, взаимодействия и снимки для моделей с поддержкой изображений.
- `/computer` на Windows выбирает окно для чтения, снимков и подтверждаемого ввода. Изображения MCP и снимки браузера добавляются только в следующий запрос.
- `/web` подключает SearXNG или Brave и умеет читать публичные текстовые страницы.
- Добавлены десять встроенных скиллов и прямой запуск из `/skills`.
- Менеджер моделей доступен внутри агента. Добавлены каталог, автонастройка, расширенный reasoning и OpenAI Responses. Результаты нативных вызовов возвращаются провайдеру по идентификатору.
- Панели обновляют изменившиеся строки, а ошибки провайдера и инструментов видны в истории чата. Несколько вызовов инструментов из одного ответа выполняются по порядку с прежними подтверждениями.
- `/model` добавляет ещё одну модель на сохранённом подключении через **N**. **F5** использует каталог и проверяет рассуждение коротким запросом. В чате текст можно выделить мышью и скопировать через **Ctrl+C**.


## 0.1.0-alpha.6 — 2026-11-16

### CarryCode Agent

- Добавлен показ reasoning: live-стриминг, сохранение в истории, свёрнутый блок с раскрытием по **F3**. Поддержаны OpenAI `reasoning_content`/`reasoning`/`thinking` и Anthropic `thinking_delta`.
- Добавлена команда `/reasoning` с уровнями **выкл / низкий / средний / высокий**. Уровень сохраняется для активной модели; для OpenAI отправляется `reasoning_effort`, для OpenRouter — объект `reasoning`, для Anthropic — extended thinking с бюджетом.
- В форме `/model` появились окно контекста, лимит входа, лимит ответа, уровень reasoning и способ его передачи. Вход проверяется по реальному телу запроса до сети; превышение показывает числа и подсказку. `max_tokens` теперь передаётся провайдеру вместо жёстких 4096.
- Добавлена проверка подключения: **t** в `/model` отправляет минимальный запрос без инструментов и reasoning.
- Ошибки провайдера показывают HTTP-статус и тело ответа в прокручиваемой панели; ключ вырезается из текста.
- Добавлена команда `/exit` (алиас `/quit`) для возврата в главное меню.
- История ответа листается колесом мыши, **PgUp/PgDn** и **Shift+↑/↓**. Включён захват колеса мыши для агентского экрана.
- Одиночный **Esc** больше не выходит из агента: он закрывает меню, очищает ввод или останавливает ответ. Выход — `/exit`, `/quit`, два **Ctrl-C** или **Ctrl-D**.
- Полный кадр перерисовывается через synchronized output, а быстрый ввод объединяется в один кадр — меньше мерцания при наборе.
- Форма модели скроллится на маленьких терминалах (проверено на 40×14), подсказки сокращаются и не обрезаются посреди слова.
- Reasoning хранится до 32 КиБ на сообщение; старые профили без новых полей загружаются.
- Профиль: `protect` добавляет явный доступ текущего пользователя к временному каталогу, чтобы работать под filtered/task-токенами.
- Исправлено ограничение чтения файла: снова 64 КиБ (было случайно уменьшено до 32 КиБ).
