## 0.1.0-beta.6 — 2026-11-18

- Выпущены два установщика Windows. Lite включает CarryCode Agent, а Full также содержит Codex CLI и OpenCode для Windows и Linux.

- `/search` отправляет интернет-запросы через SearXNG или Brave Search. Разрешения можно сменить во время работы, настройки модели применяются со следующего запроса.
- Новые чаты начинают с режима «Подтверждать за меня». Веб-поиск запускается без подтверждения и отменяется по Esc. При выборе локального SearXNG CarryCode проверяет, что сервер отвечает на поисковый запрос.
- Исправлены всплывающие ошибки загрузки рантаймов Windows и простые цепочки `&&` в Windows PowerShell 5.1.


- Диалоги, подтверждения команд и изменения проекта доступны на экране чата. Новый чат начинает с чистой статистики, а остановка ответа сохраняет черновик.
- Добавлены подсказки по `/` и `@`, копирование выделения через несколько экранов и команда `/permissions`.
- Shell выбирает PowerShell 7 при наличии, показывает код завершения и сохраняет вывод при остановке. Автоматические команды используют песочницу, а запасной запуск требует разового подтверждения.


- Добавлены создание проекта и файлов, подтверждение группы правок и проверяемая отмена. Агент умеет читать диапазоны строк, искать по шаблону, смотреть Git-статус и diff.
- Добавлены shell с подтверждением и раздельным выводом stdout/stderr, предварительный просмотр статических сайтов и обнаружение типовых задач проекта.
- Rust-клиент `/browser` запускает установленный Chromium в фоне и даёт агенту дерево страницы, консоль, ошибки сети, взаимодействия и снимки для моделей с поддержкой изображений.
- `/computer` на Windows выбирает окно для чтения, снимков и подтверждаемого ввода. Изображения MCP и снимки браузера добавляются только в следующий запрос.
- `/web` подключает SearXNG или Brave и умеет читать публичные текстовые страницы.
- Добавлены десять встроенных скиллов и прямой запуск из `/skills`.
- Менеджер моделей доступен внутри агента. Добавлены каталог, автонастройка, расширенный reasoning и OpenAI Responses. Результаты нативных вызовов возвращаются провайдеру по идентификатору.
- Панели обновляют изменившиеся строки, а ошибки провайдера и инструментов видны в истории чата. Несколько вызовов инструментов из одного ответа выполняются по порядку с прежними подтверждениями.
- `/model` добавляет ещё одну модель на сохранённом подключении через **N**. **F5** использует каталог и проверяет рассуждение коротким запросом. В чате текст можно выделить мышью и скопировать через **Ctrl+C**.


## 0.1.0-alpha.6 — 2026-11-16

### CarryCode Agent

- Добавлен показ reasoning: live-стриминг, сохранение в истории, свёрнутый блок с раскрытием по **F3**. Поддержаны OpenAI `reasoning_content`/`reasoning`/`thinking` и Anthropic `thinking_delta`.
- Добавлена команда `/reasoning` с уровнями **выкл / низкий / средний / высокий**. Уровень сохраняется для активной модели; для OpenAI отправляется `reasoning_effort`, для OpenRouter — объект `reasoning`, для Anthropic — extended thinking с бюджетом.
- В форме `/model` появились окно контекста, лимит входа, лимит ответа, уровень reasoning и способ его передачи. Вход проверяется по реальному телу запроса до сети; превышение показывает числа и подсказку. `max_tokens` теперь передаётся провайдеру вместо жёстких 4096.
- Добавлена проверка подключения: **t** в `/model` отправляет минимальный запрос без инструментов и reasoning.
- Ошибки провайдера показывают HTTP-статус и тело ответа в прокручиваемой панели; ключ вырезается из текста.
- Добавлена команда `/exit` (алиас `/quit`) для возврата в главное меню.
- История ответа листается колесом мыши, **PgUp/PgDn** и **Shift+↑/↓**. Включён захват колеса мыши для агентского экрана.
- Одиночный **Esc** больше не выходит из агента: он закрывает меню, очищает ввод или останавливает ответ. Выход — `/exit`, `/quit`, два **Ctrl-C** или **Ctrl-D**.
- Полный кадр перерисовывается через synchronized output, а быстрый ввод объединяется в один кадр — меньше мерцания при наборе.
- Форма модели скроллится на маленьких терминалах (проверено на 40×14), подсказки сокращаются и не обрезаются посреди слова.
- Reasoning хранится до 32 КиБ на сообщение; старые профили без новых полей загружаются.
- Профиль: `protect` добавляет явный доступ текущего пользователя к временному каталогу, чтобы работать под filtered/task-токенами.
- Исправлено ограничение чтения файла: снова 64 КиБ (было случайно уменьшено до 32 КиБ).
